# Кинотеатр «Звезда» — продажа билетов

Курсовой проект по МДК.09.01. Стек: Python, FastAPI, Jinja2, SQLAlchemy, PostgreSQL, Bootstrap 5, Chart.js.

## Возможности

- **Касса для планшета** — плитки фильмов дня в стиле Windows 8, время сеансов и свободные места на плитке;
  схема зала с выбором мест касанием, продажа до 10 билетов за раз, оплата картой или наличными,
  печать билетов, «Мои продажи» за смену.
- **Бухгалтер** — финансовый дашборд: выручка по дням (карта / наличные), сравнение с прошлым периодом,
  средний чек, заполняемость залов, выручка по фильмам и дням недели, продажи по кассирам, выгрузка в Excel (CSV).
- **Администратор** — дашборд дня, фильмы с постерами, расписание-таймлайн по залам с проверкой пересечений,
  журнал продаж с возвратом билетов, управление сотрудниками.
- Постеры рисуются приложением в цветах жанра (SVG); можно указать ссылку на свою картинку.

## Запуск на своём компьютере

1. В файле `.env` указать адрес своей БД:
   `DATABASE_URL=postgresql://postgres:ПАРОЛЬ@localhost:5432/kino_db`
2. Установить зависимости (в активированном виртуальном окружении):
   `pip install -r requirements.txt`
3. Запустить из папки `kino`:
   `python run.py`
4. Открыть http://127.0.0.1:8000

При первом запуске (и если структура базы устарела) таблицы и тестовые данные создаются автоматически:
16 дней расписания и несколько тысяч продаж, чтобы графики были наполнены.
Чтобы вернуть тестовые данные к исходным: `python init_db.py`.

## Публикация на Railway

1. Залить папку `kino` в репозиторий на GitHub (файлы `.env` и `.venv` не попадут — они в `.gitignore`).
2. На railway.com: **New Project → Deploy from GitHub repo** → выбрать репозиторий.
3. В том же проекте: **+ Create → Database → PostgreSQL**.
4. В сервисе приложения: **Variables → New Variable**:
   `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
5. **Settings → Networking → Generate Domain** — появится адрес вида `https://....up.railway.app`.

Команда запуска (`python run.py`) берётся из `railway.json`.
